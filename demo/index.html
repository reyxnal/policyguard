PolicyGuard

An on-chain counterparty & policy check for AI agents that pay — built for NEAR HACKATHON (Security track). Before an agent sends funds, it asks: allow, warn, or block? — and why. NEAR testnet no wallet needed for this demo

This page needs to be served over HTTP(S) for its modules to load (opening it as a file:// URL blocks them). Serve this folder, e.g. python3 -m http.server in the repository root, then open http://localhost:8000/demo/ — or use the hosted demo linked in the README.
